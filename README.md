# Радиокалькулятор — прототип

Программный калькулятор **радиодальности и радиотени** для трасс 0–200 км.

Реализовано на Python с использованием:

- **ITU-R P.526-style** дифракция (knife-edge)
- Свободное пространство + приближённое газовое затухание
- Координаты **СК-42 (Пулково-1942)** ↔ **WGS84**
- Рельеф: SRTM HGT (если есть) или **синтетический** для демо
- Учёт усиления антенн, ширины луча, поляризации
- Построение профиля трассы с зоной Френеля
- Круговая диаграмма покрытия (полярная сетка)

> Полная рекомендация ITU-R P.2001 в прототипе **не реализована** (слишком объёмна).  
> Ядро можно расширять до P.2001 / COST-231 и т.д.

---

## Быстрый старт

```bash
cd radio_calculator
pip install -r requirements.txt

# CLI-пример (точка–точка + профиль)
python main.py --freq 433.92 --tx-h 30 --rx-h 10

# С круговой диаграммой (дольше)
python main.py --coverage --max-range 25

# Интерактивный веб-интерфейс
streamlit run app/streamlit_app.py
```

Результаты CLI сохраняются в `output/profile.png` и `output/coverage.png`.

## Примеры параметров

| Параметр              | Значение по умолчанию |
|-----------------------|-----------------------|
| Частота               | 433.92 МГц            |
| Мощность Tx           | 30 дБм (1 Вт)         |
| Усиление Tx           | 8 дБи (сектор 60°)    |
| Чувствительность Rx   | −105 дБм              |
| Высота Tx / Rx        | 30 / 10 м             |
| k-фактор              | 4/3                   |

## Добавление реальных HGT-тайлов

1. Скачайте тайлы SRTM 3″ (или 1″) для нужного района, например с  
   https://dwtkns.com/srtm/ или EarthExplorer.
2. Положите файлы вида `N55E037.hgt` в `data/hgt/`.
3. Калькулятор автоматически использует их вместо синтетики.
