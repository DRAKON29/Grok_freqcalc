# Радиокалькулятор (dev_union)

Объединение двух прототипов:

| Источник | Взято |
|----------|--------|
| **GigaStudio `dev`** (GitVerse) | Next.js UI, СК-42, HGT/SRTM, IndexedDB, Vincenty, Deygout + Bullington (P.526), FSPL (P.525), зона покрытия, вертикальный срез, траектория JSON, карта Leaflet |
| **Grok_freqcalc** (GitHub) | Синтетический рельеф (демо без HGT), свип частот `frequencySweep`, экспорт JSON/CSV |

## Возможности

- Координаты **СК-42** (градусы B/L или Гаусс–Крюгер X/Y)
- Реальные файлы **SRTM .hgt** + кэш в браузере
- **Синтетический рельеф** — чекбокс в блоке «Рельеф» (только для демо)
- Бюджет линии, профиль с зоной Френеля
- Дифракция: **Дейгаут / Буллингтон** (берётся большая оценка)
- Круговая зона связи, вертикальный анализ
- Диапазоны частот Tx/Rx
- **Экспорт JSON / CSV** результатов трассы (CSV включает L(f) в режиме диапазона)

## Запуск

```bash
bun install   # или npm install / pnpm install
bun run dev   # http://localhost:3000
```

Node.js ≥ 24 (см. `package.json`).

## Структура

```
src/lib/radio/       — математика (engine, pathloss, sk42, hgt, synthetic, …)
src/components/radio — UI (калькулятор, карта, графики)
```

## Ограничения

- Полный **ITU-R P.2001** не реализован (используются P.525 + P.526).
- Синтетический рельеф не заменяет SRTM для проектных расчётов.
- Модель справочная; для ответственных задач сверяйтесь с ITU-R и картами рельефа.
