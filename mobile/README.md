# Мобильное приложение (PWA)

Веб-приложение, оптимизированное под телефон. Работает в браузере Android / iOS  
и может быть **установлено на домашний экран** как обычное приложение.

## Запуск

Из корня проекта:

```bash
cd radio_calculator
pip install -r requirements.txt   # fastapi uvicorn уже нужны
uvicorn mobile.api:app --host 0.0.0.0 --port 8080
```

Откройте на телефоне (в одной сети с ПК):

```
http://<IP-вашего-ПК>:8080
```

Узнать IP: `ip addr` / `ipconfig`.

### Установка на телефон

**Android (Chrome):** меню → «Установить приложение» / «Добавить на главный экран».  
**iOS (Safari):** «Поделиться» → «На экран Домой».

## Возможности

- Расчёт трассы Tx → Rx (потери, Pr, запас / радиотень)
- Профиль рельефа с зоной Френеля
- Круговая диаграмма покрытия
- СК-42 и WGS84
- Параметры антенн, поляризация, k-фактор

## Ограничения

- Нужен доступ к серверу (расчёты на Python-бэкенде)
- Офлайн доступен только интерфейс; сами расчёты требуют сеть
- Для APK/IPA можно обернуть эту PWA в Capacitor / TWA
